# ReadQuest English — かんたん操作ガイド（利用者向け）

## はじめに

ReadQuest English は「英単語から、英語で本を読む力へ。」を目標にした学習アプリです。
インストール不要でブラウザから使え、学習記録はお使いの端末内に保存されます。

## 画面の使い方

- **ホーム**：今日の目標（例：10問）の進み具合、学習の続き、復習が必要な単語数が分かります。
- **単語**：単語を検索・選択すると、意味・品詞・発音記号・例文・スペル練習が見られます。「発音を聞く」で音声が再生されます（端末が対応している場合）。
- **ゲーム**：4種類から選びます。5問ごとに結果が出て、間違えた単語は復習リストに入ります。
- **復習**：間違えた単語や、覚えたか確かめたい時期の単語が出ます。「復習セッション開始」で10問ずつ解けます。
- **読解**：短い英文から長い説明文まで10編。まず英語だけで読み、分からなければ訳を表示します。問題を解いて「採点する」を押すと解説が出ます。
- **記録**：学習日数・正答率・グラフ、目標や文字サイズの変更、データの初期化ができます。

## よくある質問

- **オフラインで使えますか**：一度開いた画面は、電波がなくても使える場合があります。初めて開く画面は通信が必要です。
- **音が出ません**：端末の音量・ミュートを確認してください。対応していない端末では音声ボタンの代わりに文字で案内が出ます。
- **記録が消えましたか**：記録は端末のブラウザ内に保存されます。ブラウザのデータ削除や初期化操作を行うと消えます。
- **データを消したい**：記録画面の「データを初期化する」から2段階の確認を経て削除できます。
