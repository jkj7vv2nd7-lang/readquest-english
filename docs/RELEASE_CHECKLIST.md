## 公開手順メモ

1. `npm run build` で `dist/` を生成
2. `dist/` を静的ホスティングに配置（同一オリジン配信がSWの条件）
3. 配置後に上記「手動確認」を実施し、本チェックリストに結果を追記する
4. 改版時は `src/version.ts` と `package.json` の version を同時に上げ、SWの `CACHE` 名も上げる
5. デプロイ・外部アップロード・プッシュは依頼者の明示指示なしに実行しない
